재부팅해도
Claude Code 세션은 그대로 Reboot.
Your Claude Code sessions come back.

열어 둔 Claude Code 세션과 Claude Desktop 창을 저장해 두었다가, 다시 로그인하면 폴더와 대화까지 그대로 되살립니다. 탭을 하나씩 다시 여는 일은 이제 그만. Session Keeper saves every running Claude Code session and your Claude Desktop window layout, then brings them back after you sign in again: same folders, same conversations. No more reopening tabs one by one.

버튼 하나로 저장하고, 로그인하면 돌아옵니다One click before, nothing after

Windows 업데이트나 드라이버 설치로 재부팅해야 할 때, 터미널마다 폴더를 찾아가 claude --resume을 칠 필요가 없습니다. When Windows Update or a driver install wants a restart, you don't have to cd into every folder and type claude --resume again.

스냅샷 → 재부팅Snapshot → Restart

지금 열린 세션의 폴더와 세션 ID, Desktop 창 위치를 저장하고 재부팅을 예약합니다. 마음이 바뀌면 취소할 수 있습니다.Saves each session's folder and ID plus Desktop window positions, then schedules the restart. You can still cancel.

로그인Sign in

앱이 트레이에서 시작하고 잠시(기본 20초) 기다립니다. 그 사이 트레이 메뉴에서 복원을 취소할 수 있습니다.The app starts in the tray and waits a moment (20 s by default). You can cancel the restore from the tray menu.

그대로 복원Everything's back

세션마다 원래 폴더에서 claude --resume <ID>로 대화를 이어 엽니다. Windows Terminal 탭으로 묶거나 창을 따로 열 수 있습니다.Each session reopens in its own folder with claude --resume <ID>, grouped as Windows Terminal tabs or as separate windows.

기능Features

가볍게 트레이에 머무르며, 필요한 순간에만 나섭니다.Sits quietly in the tray and steps in only when you need it.

실행 중인 세션 한눈에See what's running

세션별 작업 폴더, 세션 ID, 첫 질문, 셸과 터미널 종류. Desktop 창 위치와 상태까지.Folder, session ID, first prompt, shell and terminal for every session, plus Desktop window placement.

재부팅 후 자동 복원Restore after restart

스냅샷과 재부팅(또는 시스템 종료)을 한 번에. 다음 로그인 때 자동으로 되살립니다.Snapshot and restart (or shut down) in one step; the next sign-in restores automatically.

자동저장Autosave

기본 5분마다 저장해 두므로, 예고 없이 재부팅되어도 직전 상태가 남습니다.Saves every 5 minutes by default, so an unexpected reboot still leaves you a recent state.

골라서 복원Pick what to restore

지난 스냅샷을 열어 원하는 세션만 체크해서 되살립니다.Open any saved snapshot and tick only the sessions you want back.

Windows Terminal 탭Windows Terminal tabs

복원한 세션을 한 창의 탭으로 묶어 엽니다. 셸은 PowerShell 7이나 Windows PowerShell.Restored sessions open as tabs in one window, in PowerShell 7 or Windows PowerShell.

정확한 세션 짝짓기 (선택)Exact session mapping (optional)

Claude Code의 SessionStart 훅을 설치하면 같은 폴더에서 세션을 여러 개 돌려도 정확히 구분합니다.Install the Claude Code SessionStart hook to tell apart several sessions running in the same folder.

예고 없는 재부팅에는 이렇게When Windows restarts on its own

업데이트나 정전으로 갑자기 재부팅됐을 때 무엇을 할지 설정에서 고릅니다. 앱의 "스냅샷 → 재부팅"으로 한 재부팅은 항상 자동으로 복원합니다.Choose what happens after an update or power cut restarts the PC. Restarts you start with "Snapshot → Restart" always restore automatically.

복원할지 묻기Ask firstDEFAULT

마지막 자동저장 시각을 보여 주고 복원할지 묻습니다.Shows when the last autosave was taken and asks before restoring.

묻지 않고 복원Restore automatically

대기 시간 뒤 바로 복원합니다. 트레이에서 취소할 수 있습니다.Restores after the wait. Cancel from the tray if you change your mind.

아무것도 안 하기Do nothing

자동저장만 계속하고 복원은 직접 고를 때만 합니다.Keeps autosaving, restores only when you choose a snapshot yourself.

개인정보Privacy

네트워크 통신 기능이 없습니다. 아무것도 수집하거나 보내지 않습니다. 모든 기록은 이 PC의 앱 데이터 폴더에만 남습니다.The app has no networking code. Nothing is collected or sent anywhere; everything stays in the app's data folder on your PC.

알아 둘 점Good to know

  • Desktop 창 안의 대화는 밖에서 읽을 수 없어 복원하지 않습니다. 창 배치와 실행 여부만 되돌립니다.Conversations inside Claude Desktop can't be read from outside, so only window placement is restored.
  • 응답을 생성하는 도중에 재부팅하면 그 응답은 끊깁니다. 대화 기록은 남아 있어 이어 갈 수 있습니다.A reply being generated during the restart is cut off; the conversation itself is kept and can be resumed.
  • 앱 화면은 현재 한국어만 지원합니다.The app's interface is currently Korean only. The window shown above is translated for this page.
  • 터미널 창의 화면 위치는 복원하지 않습니다.Terminal window positions are not restored.
  • 오래 쉬었던 대화는 Claude Code가 "Resume this conversation?"을 물을 수 있습니다. Resume을 고르면 이어집니다.Long-idle conversations may get a "Resume this conversation?" prompt from Claude Code. Pick Resume.
