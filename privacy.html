Privacy Policy

Session Keeper for Claude Code · Last updated: November 4, 2026

Session Keeper for Claude Code ("the app") does not collect, store on any server, or transmit any personal data. The app contains no networking code and never connects to the internet.

Information the app reads on your PC

  • The list of running processes and, for each, its executable path, command line and working folder. Used to find Claude Code and Claude Desktop.
  • The titles and positions of Claude Desktop windows. Used to restore the window layout.
  • The beginning of conversation history files under %USERPROFILE%\.claude\projects\. Used to show each session's title (its first prompt).

Information the app writes on your PC

  • Snapshots, settings, logs and session-mapping records, in the app's data folder (its path is shown on the Settings tab).
  • %USERPROFILE%\.claude\settings.json, only to add or remove the optional SessionStart hook when you press the hook install or remove button. Before adding the hook for the first time the app saves a backup next to it as settings.json.csk-bak. If the app has been moved to a different folder, it updates the path of the hook it installed earlier.
  • Portable version only, if you turn on "Start with Windows": a value under HKCU\Software\Microsoft\Windows\CurrentVersion\Run. The Microsoft Store version uses the standard Windows startup task instead, which you can turn off in Task Manager or Settings.

None of this information leaves your PC.

Third parties

The app does not share data with anyone, contains no analytics or advertising, and makes no purchases. When it restores a session it starts Claude Code or Claude Desktop on your PC; how those programs handle your data is covered by Anthropic's own policies.

Deleting your data

  • Press "Remove hook" on the Settings tab, then delete the app's data folder. That removes everything the app created.
  • Uninstalling the Microsoft Store version also deletes its data folder. Remove the hook in the app before uninstalling; otherwise delete the csk-hook.exe entry from settings.json yourself.

Changes

If this policy changes, the new version will be posted on this page with a new date.

Contact

Open an issue at github.com/Coldlapse/session-keeper-for-claude-code/issues.

개인정보 처리방침

Session Keeper for Claude Code · 최종 수정: 2026년 11월 4일

Session Keeper for Claude Code(이하 "앱")는 어떤 개인정보도 수집하거나, 서버에 저장하거나, 외부로 보내지 않습니다. 앱에는 네트워크 통신 기능이 없고 인터넷에 접속하지 않습니다.

앱이 이 PC에서 읽는 정보

  • 실행 중인 프로세스 목록과 각 프로세스의 실행 경로, 명령줄, 작업 폴더. Claude Code와 Claude Desktop을 찾는 데 씁니다.
  • Claude Desktop 창의 제목과 위치. 창 배치를 복원하는 데 씁니다.
  • %USERPROFILE%\.claude\projects\ 안 대화 기록 파일의 앞부분. 세션 제목(첫 질문)을 표시하는 데 씁니다.

앱이 이 PC에 쓰는 정보

  • 스냅샷, 설정, 로그, 세션 매핑 기록. 앱 데이터 폴더에 저장합니다(경로는 설정 탭에 표시).
  • %USERPROFILE%\.claude\settings.json. 훅 설치·제거 버튼을 누를 때만 선택 기능인 SessionStart 훅을 넣거나 뺍니다. 처음 넣기 전에 같은 폴더에 settings.json.csk-bak으로 백업합니다. 앱을 다른 폴더로 옮겼다면, 앞서 설치한 훅의 경로를 새 위치로 고칩니다.
  • 포터블 버전에서 "Windows 시작 시 실행"을 켠 경우에만 HKCU\Software\Microsoft\Windows\CurrentVersion\Run에 값을 씁니다. Microsoft Store 버전은 Windows 표준 시작 작업을 쓰며, 작업 관리자나 설정에서 끌 수 있습니다.

이 정보는 모두 PC 밖으로 나가지 않습니다.

제3자

앱은 누구와도 데이터를 공유하지 않고, 분석·광고 기능이나 결제가 없습니다. 세션을 복원할 때는 이 PC에서 Claude Code나 Claude Desktop을 실행할 뿐이며, 그 프로그램들의 데이터 처리는 Anthropic의 정책을 따릅니다.

삭제

  • 설정 탭에서 "훅 제거"를 누른 뒤 앱 데이터 폴더를 지우면 앱이 남긴 것이 모두 지워집니다.
  • Microsoft Store 버전은 앱을 제거하면 데이터 폴더도 함께 지워집니다. 훅은 제거하기 전에 앱에서 해제하세요. 이미 제거했다면 settings.json에서 csk-hook.exe 항목을 직접 지우면 됩니다.
